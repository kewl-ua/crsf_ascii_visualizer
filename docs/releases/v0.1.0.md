# crsf-viz 0.1.0

First Linux command-line release of CRSF ASCII Visualizer.

- Run `crsf-viz` directly from Bash after installation.
- Read CRSF over UDP, UART, UNIX datagram, UNIX stream, or stdin.
- Inspect sixteen RC channels as Mode 2 sticks, pulse widths, and AUX switch positions.
- Use `--help`, `--version`, and `man crsf-viz` for usage reference.
- Keep incoming stdin bytes separate from terminal keyboard input and screen output.
- Get an actionable error for unavailable devices, sockets, or dependencies.
- Keep receiving data while a small terminal displays a resize prompt.

## Install on Debian or Ubuntu

Download the `.deb` release asset, then install it with:

```bash
sudo apt install ./crsf-ascii-visualizer_0.1.0_all.deb
crsf-viz --version
man crsf-viz
```

UART input requires `pyserial` (`python3-serial` on Debian and Ubuntu).

## Install from source

Extract the source distribution and run:

```bash
make install PREFIX="$HOME/.local"
export PATH="$HOME/.local/bin:$PATH"
crsf-viz --udp 127.0.0.1:5555
man -l "$HOME/.local/share/man/man1/crsf-viz.1"
```

Use `make uninstall PREFIX="$HOME/.local"` to remove this installation.
For a system installation, use `sudo make install PREFIX=/usr/local`.

The release also includes a Python wheel. Python 3.10 or newer and a terminal
with curses support are required. The `serial` extra installs the optional
UART dependency. `python3 -m crsf_ascii_visualizer` and `python3 main.py` remain
available for source-based use.

Source inputs are mutually exclusive. UNIX datagram socket paths must not
already exist; UNIX stream servers must already be listening. Stdin mode
requires a controlling terminal. The full interface needs 80 columns by
33 rows or more.
