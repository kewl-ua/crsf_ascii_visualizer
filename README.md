# CRSF ASCII Visualizer

Стики и AUX-каналы CRSF прямо в терминале. Два стика в раскладке Mode 2, значения каналов в микросекундах и положения двенадцати AUX-переключателей — на одном экране.

![CRSF ASCII Visualizer: движение стиков и переключение AUX-каналов](docs/assets/crsf-terminal.gif)

*Демо использует тестовые CRSF-пакеты с корректной CRC, 250 Гц. Содержимое экрана получено из исходного кода приложения.*

## Что показывает

- Положение левого стика **Throttle / Yaw** и правого **Roll / Pitch**.
- Значения всех 16 каналов; для AUX — шкалу и положение **LOW / MID / HIGH**.
- Счётчик принятых RC-пакетов, частоту входящего потока (`fps`) и состояние связи.
- `NO SIGNAL` после 0,5 секунды без RC-пакетов. Последние значения остаются на экране до восстановления потока.

Входные данные — сырые CRSF-фреймы `RC_CHANNELS_PACKED` (`0x16`). Проверка CRC отбрасывает повреждённые пакеты. Перерисовка экрана ограничена 30 Гц; `fps` показывает частоту приёма пакетов.

## Быстрый запуск

Нужны Python 3 и терминал с поддержкой `curses` в Linux или macOS. Рекомендуемый размер окна — **88 столбцов × 34 строки** или больше, чтобы видеть все AUX-каналы.

```bash
git clone git@github.com:kewl-ua/crsf_ascii_visualizer.git
cd crsf_ascii_visualizer
python3 main.py --udp 127.0.0.1:5555
```

Направьте сырые CRSF-фреймы на `127.0.0.1:5555`. Для UDP достаточно стандартной библиотеки Python. Чтобы принимать пакеты с других устройств, используйте `--udp 0.0.0.0:5555` — это также адрес прослушивания по умолчанию.

## Источники данных

### UART

Для прямого подключения к последовательному порту установите `pyserial`:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install pyserial
python main.py --serial /dev/ttyUSB0 --baud 420000
```

Укажите свой порт и скорость. Значение `--baud` по умолчанию — `420000`.

### UNIX datagram

Программа создаёт и слушает локальный datagram-сокет. Отправляйте CRSF-фреймы в указанный путь:

```bash
python3 main.py --unix-dgram /tmp/crsf.sock
```

### UNIX stream

Программа подключается к уже работающему серверу UNIX stream:

```bash
python3 main.py --unix-stream /tmp/crsf.sock
```

## Раскладка каналов

| Канал | Функция | Отображение |
| --- | --- | --- |
| CH1 | Roll | Правый стик, горизонталь |
| CH2 | Pitch | Правый стик, вертикаль |
| CH3 | Throttle | Левый стик, вертикаль |
| CH4 | Yaw | Левый стик, горизонталь |
| CH5–CH16 | AUX1–AUX12 | Шкала, микросекунды и LOW / MID / HIGH |

## Управление

**`q`**, **`Esc`** или **`Ctrl+C`** — выход.

Все параметры запуска:

```bash
python3 main.py --help
```

Команды Makefile:

```bash
make help
```
